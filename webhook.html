Discord alerts.

Post to a Discord channel, and ping the roles you choose, every time someone checks in on Clappia. Set one up per server or channel. Your settings are saved only on this device, never online.

1 Discord webhook

In the Discord app: open the server → Server Settings → Integrations → Webhooks → New Webhook. Pick the channel alerts should go to, then Copy Webhook URL and paste it here. The webhook decides the channel; make another one for each channel or server.

2 Who gets pinged

OnRole name (for you)Role ID

Untick a role to leave it out without deleting it. Getting a role ID on iPhone: in Discord tap your profile picture → Settings → App Settings → Advanced and turn on Developer Mode. Then open the server → tap its name → Settings → Roles, long-press the role (or open it and tap ⋯) → Copy Role ID. It’s a long number, about 18–19 digits.

Clappia also creates a blank "System Workflow" record after each check-in. Discord rejects alerts with empty fields, so those won't post, but if you see blank alerts, add an If condition before this node: Hottie Name is not empty.

Another server or channel? Make a webhook there, paste it in step 1 (pick its roles), and add a second REST API node with the new Server Url and Body.
